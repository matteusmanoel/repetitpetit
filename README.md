# Repeti Petit

E-commerce de brechó infantil para a **Repeti Petit** de Foz do Iguaçu — plataforma
self-service que elimina a dependência de WhatsApp no fluxo de compra online.

## Stack

Next.js App Router · TypeScript strict · Tailwind CSS · shadcn/ui · Supabase ·
Mercado Pago · React Hook Form + Zod · pnpm

## Supabase project

Ref: `wcgpamsvnhpgonxzbzlg` — já vinculado via CLI.

## Setup rápido

```bash
pnpm install
cp .env.example .env.local   # preencha as variáveis
pnpm dev
```

Veja `docs/07-setup.md` para o fluxo completo.
