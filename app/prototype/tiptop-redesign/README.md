# TipTop → Repeti redesign prototype

**Throwaway.** Do not promote these components to production routes.

## Question

> Como deve parecer o storefront Repeti com estrutura TipTop e identidade Repeti?

## Run

```bash
pnpm dev
# open http://localhost:3000/prototype/tiptop-redesign?variant=T
```

Default **T**. Arrow keys / floating bar: `T | A | B | C`.

## Variants

| Key | Name | Role |
|---|---|---|
| **T** | TipTop target | **Winner (rev. 2)** — TipTop layout hard-copy + Repeti colors + Omnes/Becca stand-ins |
| A | Dense commerce | Early dense pass (comparison) |
| B | Soft kids boutique | Rounded reference — good mobile, too airy on desktop |
| C | Fluid editorial | Out for default storefront |

## Fonts in prototype

- `--font-omnes` ← Fredoka (stand-in for Omnes)
- `--font-becca` ← Caveat (stand-in for Becca)

Replace with licensed files before production.
